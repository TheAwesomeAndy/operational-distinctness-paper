# Post-Acceptance Visibility Plan (TAFFC)

Activated **only after** formal acceptance. No promotion language belongs in the manuscript itself.
Respect any publisher embargo before posting anything publicly.

## Tracking
- Record the acceptance date, the DOI once issued, and the expected publication/issue date.
- Note the publisher's embargo and self-archiving (green/gold OA) terms before any public post.

## Visual summary
- Prepare a one-panel graphical abstract / visual summary derived from the existing Fig. 1 overview
  (ERP observation → reservoir/BSC₆ → E/D/T/C evidence streams → ablation/perturbation/closed-loop).
  Keep it claim-disciplined (measurement substrate, not classifier superiority).

## Institutional and social
- Optional department / university press-release or research-highlight request, using the abstract's
  bounded language (no diagnostic or deployment claims).
- LinkedIn post draft: one paragraph on the idea (operationally distinct affective-ERP evidence
  streams), with the bounded scope explicit; link to the version of record once embargo allows.
- Short technical thread draft (3–5 posts): problem → observable-map idea → the four streams →
  perturbation/closed-loop finding → bounded scope and data-governance note.

## Scholarly amplification
- Repository / supplement citation instructions: cite the version of record; point to aggregate
  outputs and scripts "where permissible" (no restricted data, no private paths).
- Conference-talk conversion: a 12–15 minute talk reusing the figure set; emphasize the measurement
  framing and the perturbation operating-regime result.

## Guardrails
- No "breakthrough/revolutionary/state-of-the-art" framing in any post.
- Keep the not-claimed boundaries (no online BCI, no diagnostic validation, no hardware-energy) in
  public summaries, exactly as in the paper.
- Do not disclose restricted dataset details or any identifiers.
