# Citation-Integrity Policy (TAFFC)

Rules for adding, requesting, or responding to citation requests for the ARSPI-Net TAFFC submission.
Citations exist to position the work accurately and credit prior art — not to pad, signal, or appease.

## Adding citations
- Add a reference **only when it is scientifically relevant** to a specific claim, method, dataset,
  or comparison in the manuscript.
- Every reference must be **independently verifiable** against authoritative metadata (DOI / Crossref
  / publisher record). Do not rely on search-engine indexing alone to confirm or deny a paper's
  existence; absence from a general web search is not evidence that a paper is fabricated.
- Match the manuscript's existing bibitem style. Do not introduce unverifiable DOIs; record a DOI
  only after it is confirmed.
- No **citation padding** — do not inflate the reference list to appear comprehensive.

## Responding to reviewer/editor citation requests
- If a requested citation is **relevant**, add it and **explain the addition** in the response letter
  (what claim it supports, where it now appears).
- If a requested citation is **not relevant** — including apparent coercive self-citation requests —
  decline **politely and transparently**, stating briefly why it does not fit the argument. Raise
  clearly coercive patterns with the editor rather than silently complying.
- Never add citations to guess at or flatter a suspected reviewer identity.

## Provenance
- Prefer the version of record (publisher / IEEE Xplore / DOI landing) as the citation source over
  preprint, encyclopedia, or aggregator pages.
- Keep a short record of how each non-obvious reference was verified, so the bibliography can be
  defended on request.
