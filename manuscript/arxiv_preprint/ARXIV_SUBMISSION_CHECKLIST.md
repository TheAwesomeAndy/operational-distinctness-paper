# arXiv submission checklist (manual; author-driven)

Pre-submission (author):
- [ ] Confirm final author list, order, affiliations, corresponding author, email, ORCID.
- [ ] Decide funding statement and conflict-of-interest text (if any).
- [ ] Decide posting timing relative to TCDS double-anonymous review (see README).
- [ ] Decide license (default arXiv non-exclusive recommended; CC is opt-in).
- [ ] Decide whether an AI-use disclosure is needed for the preprint.

Source upload:
- [ ] Upload `ARSPI-Net_arxiv_source.zip` (LaTeX source) OR `main_arxiv.pdf`.
- [ ] Primary category eess.SP; add secondaries cs.NE / cs.LG / q-bio.NC as desired.
- [ ] Paste title and plain-text abstract from `ARXIV_METADATA.md`.
- [ ] Comments: "10 pages, 5 figures, 6 tables. Preprint version."

Verify on arXiv preview:
- [ ] PDF renders 10 pages, figures/tables present, references resolved.
- [ ] Author block and affiliations correct.
- [ ] Data-availability statement is the restricted-data wording (no public-data claim).
- [ ] No private paths, pickles, or raw-data references in the rendered PDF.

Do NOT:
- [ ] Upload any blind/internal artifact.
- [ ] Claim public data or public code availability.
- [ ] Use "accepted/in press/published/under review/IEEE-approved/publisher version".
